多类别目标检测数据

上传港区船舶、浮标等通航目标的图像与框标注，自动识别类别并转换为 YOLO 检测格式。支持 WSODD 原始 VOC 压缩包。

VOC XML 格式
dataset/
  JPEGImages/    # 原图
    harbor_001.jpg
  Annotations/  # 同名 XML 检测框
    harbor_001.xml

也支持 WSODD 的 image/ + annotation/，以及 images/ + annotations/。类别从 XML 的 name 读取。

YOLO TXT 格式
dataset/
  data.yaml     # names: [boat, ship, buoy]
  images/       # 图像
    harbor_001.jpg
  labels/       # 同名 TXT 检测框
    harbor_001.txt

每行：类别 ID、中心 x、中心 y、宽、高；坐标归一化到 0–1。类别 ID 从 0 连续编号。空 TXT 表示无目标图片，缺少 TXT 会报错。

数据划分与上传限制

可提供 images/{train,val,test}/ + labels/{train,val,test}/，或 {train,val,test}/images/ + labels/；VOC 可提供 ImageSets/Main/{train,val,test}.txt。已有划分保持不变，三个集合均须非空。

未划分的数据按采集日或去除帧号后的文件名前缀分组，种子 42，约 70% / 15% / 15%，至少 3 组。请保留相机与场景前缀，并核对分组是否独立。

上传最大 4 GB，解压最大 12 GB、100000 个文件，单文件最大 64 MB。支持 ZIP / TAR / TAR.GZ / TGZ；不接收分类文件夹或分割掩膜。

面向水面场景的多类别检测

接入船舶、浮标、人员等港区水域图像，通过 YOLO 检测框理解画面中的目标。支持 WSODD 和用户上传的 VOC / YOLO 数据，类别以数据集标注为准。

结果用于实验分析与辅助观察。检测结果不能直接替代导航决策、航速测量或碰撞风险判断。

WORKFLOW
  1. 上传压缩包或文件夹，完成图像和框标注质检
  2. 冻结类别、划分和数据指纹，在远程 GPU 训练
  3. 独立测试与可视化，按类别核对效果
  4. 图片 / 视频检测后，由 DeepSeek 解读结构化摘要

项目中的工程改进

实现方式

Django + Vue 工作台

统一上传、台账、任务和可视化；算法演示也可使用 Streamlit 与 Gradio。

数据与实验可追溯

保存原始上传、SHA256 数据身份和质检历史，区分新增与已修复问题。

远程 GPU 执行

训练与推理独立运行，支持传输续接和结果归档；界面保留真实连接状态。

有依据的智能解释

大模型解读检测摘要，原始视频与模型权重保留在本机或远程 GPU。

以上为平台工程改进；当前使用 YOLOv8 基线，不宣称提出新的检测算法。完成训练与精度达标分别评审。

结果含义

输出标注视频、逐帧 JSONL、抽样检测框和类别摘要。帧出现次数和同帧最多目标数不等于视频中的独立目标数量。

DeepSeek 仅接收类别与频率等结构化摘要。没有真值标注的视频不计算准确率，不从检测结果推断航速、轨迹或碰撞风险。

模型推理必须连接远程 GPU。语言解释在本机请求 DeepSeek，可单独重试；解释失败不改变已经完成的视频检测结果。
