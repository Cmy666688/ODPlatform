# WSODD 扩展训练数据的对照实验（2026-10-27）

应用户要求，将原测试集按图片随机抽样的 80% 加入训练集，观察效果；该实验单独保存，不覆盖原始数据、原模型或原实验。原数据指纹为 `32aa25208e93f3055f2dddcccf214d7422f62b759113b1a0644cbc02b344ab0b`。

## 划分与实验

- 随机种子 42，原测试集 777 张中，622 张加入原训练集；新训练集共 6260 张。
- 原验证集保持 1052 张，原测试集剩余 155 张用于本次前后对照。完整文件清单为 `runs/accuracy_improvement/20261027/test_mix_80/split.json`。
- 被加入训练的图片和保留的 155 张共享原测试集的全部 4 个采集分组，因此保留的 155 张**不是场景独立测试集**。原测试集也已在以前反复评估。
- 从既有最佳 YOLOv8s 权重开始重新初始化优化器微调 10 轮，RTX 4090，输入 960、batch 32、AdamW、学习率 0.0001、RAM 缓存、seed 42；按原验证集指标选出本次 best。原模型与候选用同一套参数各自重新评估原验证集和保留的 155 张图。

## 结果

| 评估集合 | 指标 | 原模型 | 扩展训练模型 |
| --- | --- | ---: | ---: |
| 原验证集（1052 张） | mAP50 | 22.70% | 27.15% |
| 原验证集 | mAP50–95 | 12.39% | 13.72% |
| 保留的 155 张 | mAP50 | 28.95% | 68.58% |
| 保留的 155 张 | mAP50–95 | 13.16% | 38.68% |
| 保留的 155 张 | 精确率 | 63.26% | 68.65% |
| 保留的 155 张 | 召回率 | 29.20% | 65.10% |

155 张的结果提高明显，但由于训练集和这批图的采集组重叠，不能解释为在全新场景中达到 68.58%。不同数量、不同图片组成的测试集，其总体 mAP 也不应直接与原 777 张测试集的 24.88% 比较。155 张中 tree、grass 各仅有 2 个框，buoy 4 个框，animal 无框；类别指标容易波动或无法计算。

原验证集与原训练集的分组仍保持不变，mAP50 提升 4.45 个百分点，但该验证集已在多轮实验使用，仍需全新独立场景数据检验。各类别并非都提升：原验证集 boat AP50 为 54.13% → 53.27%，ship 为 54.14% → 56.41%，person 为 5.10% → 14.98%，animal 为 33.97% → 9.57%。

训练及逐轮验证耗时约 447.88 秒；从准备数据、基线评估、训练到候选评估总计 541.74 秒，不含权重网络回传。完整结果位于 `runs/accuracy_improvement/20261027/test_mix_80/report.json`，逐轮数据位于同目录 `results.csv`。模型权重另存，未自动替换原模型。其 SHA-256 为 `4c4f769a4b35b624b8e43a3adba31397da2d124688af8e184a2ff68e7a5ca5bd`。
